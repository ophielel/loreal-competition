# 演示讲解稿

队伍名称：待填写。作品：知微 · 消费者服务工作台。建议讲解时长 3 分钟。

## 开场（20 秒）

“客服的难点往往不是不会回复，而是信息散落在聊天、订单和不同工单里。知微把辅助能力放回客服工作台右侧，让客服看到消费者此刻的处境，以及判断背后的证据。”

## 查看风险与回放（40 秒）

打开工作台，选择 S00010。首条消息是使用面膜后发红、起疹的买家自述。右侧提示使用不适需优先关注，给出可编辑回复草稿。

点击高关注筛选、搜索 S00010；逐步回放消息，看到情绪线索如何变化。证据只限当前时点，不读取未来客服回应。原始聊天里存在医疗相关话术，展示原文不表示系统认可；新建议仅作服务分流与人工跟进。

## 解释归档与证据（45 秒）

完整回放后，工单仍不出现，因为这批数据的工单时间全部晚于聊天结束。点击“归档快照”，才能看到事后创建的不良反应工单和服务全路径。

“历史回放回答当时知道什么，归档模式回答后来发生了什么。我们把这两个问题分开。”

切到“证据与流程”，点击原话引用回到中部消息。强调每条来源可定位到工作簿 sheet!row。

## 人工闭环（45 秒）

采用回复建议，修改措辞，再模拟发送。点击创建跟进，检查任务标题与核实说明，确认后进入左侧跟进列表并标记完成。

“AI 帮助整理证据和建议，客服掌握回复和行动决定权。这个演示没有向消费者发消息，也没有连接支付或物流系统。”

## 评估与模型（30 秒）

展示评估页：官方 138 个同源开发会话的当前 Hybrid 重放为首条 83.33%、完整会话 92.75%；另有 50 条独立人工编写 Challenge Set，Intent 88.00%、风险召回 100.00%、无依据承诺拦截召回 100.00%。强调小集合只用于边界回归，不代表生产泛化。

默认规则可离线演示；Qwen 按按钮触发，未配置时说明原因并保留规则结果。真实模型上线前还需要在线验证、独立盲测和客服试用。

## 结尾（20 秒）

“我们的目标是减少找信息、问重复问题和无依据承诺。下一步用人工标注与客服实验验证这些价值，再接入经授权的业务工具。知微，让每一次对话都被认真理解。”

## 视频说明

随附约 80 秒视频由真实 Edge 浏览器执行以上交互录制；它不是静态 PPT 冒充操作。视频使用本地规则模式，无配音，中文字幕已压入画面，另附 SRT 文件。可以直接播放 MP4 或重新运行 `npm run record`。运行 `python scripts/build_video.py` 可转为 MP4（另需 imageio-ffmpeg）。讲解稿可供现场扩展到 3 分钟。
