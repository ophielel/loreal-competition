# Agent 设计与接口

## 场景与架构决策

核心使用者为人工客服。保留左侧接待、中部对话、右侧辅助插件的布局；用户不需要离开主会话去搜多张表。设计聚焦看清当前主诉、找回已有证据、确定下一步跟进。

采用 Python 标准库服务 + 原生浏览器界面，方便评委离线启动，避免对 Node 构建或外部 CDN 的运行依赖。SQLite 仅保存本地模拟任务。它是竞赛 Demo，不是已接入千牛的生产插件。

## 工作流

1. **检索与归并**：XLSX 导入器按会话 ID 关联聊天、订单、五类工单。每条证据携带 sheet!row 来源；工作簿哈希用于检查版本。脱敏昵称仅展示，不当作唯一客户标识。
2. **时点门控**：历史回放以当前消息时间为截止点。未来创建记录不入上下文；订单/工单无状态日志时显示历史状态待核实。工单完整快照仅在明确选择归档模式后显示。
3. **证据化风险扫描**：同一次匹配直接产生 `risk_type → semantic_state → level → evidence_ids`，区分实际发生、否定、假设/咨询、既往情况和待核实。只有“实际发生/待核实”能够进入当前健康高关注；否定、假设和既往状态不会因意图标签被升级。
4. **默认 Qwen 语义分析**：配置后，会话默认提交当前可见消息和最小结构化字段；对话中的指令视为不可信数据；不把 scene_major/scene_minor 传入。规则模式不作为正常产品模式，仅在未配置、请求失败或输出校验失败时安全回退。
5. **结果校验与 Hybrid**：JSON 类型、必填字段、长度、枚举和引用 ID 均需合法。引用可包含当前可见客服消息，但至少有一条买家证据；主意图证据必须来自当前可见买家。未知或未来引用直接回退。通过后，最早主诉的明确业务依据可保留规则原判，其余采用模型语义。即使 Qwen 将意图判为“不良反应”，也必须在其引用中存在同源且 `semantic_state` 为“实际发生/待核实”的健康证据，才能触发高优先级、健康分流和安全回复；意图标签本身不能充当风险证据。
6. **行动建议**：展示摘要、回复草稿和待核实事项。采用建议后可编辑，模拟发送仅留在当前浏览器页面。没有后台自动发消息工具。
7. **人工闭环**：弹窗确认任务名称和说明，写入本机 SQLite；相同会话+回放点+标题去重，客服可完成任务。不会真实退款、补发或修改外部工单。

这是受控的分步工作流，不是让多个自治代理随意操作业务系统。Qwen 适配器已完成真实账号在线评测与原始响应离线回放复核，详见 [ONLINE_EVALUATION.md](ONLINE_EVALUATION.md)。

## 模式与输入契约

会话结构包含 id、buyer、messages[]、orders[]、tickets[]。message.id 和 order.id 均为字符串，防止 19 位订单号经过 JS 数字类型丢失精度。

`cursor` 从 1 到消息总数表示历史回放，0 表示无消息状态（API 测试可用）；总数+1表示归档快照，必须显式呈现 `archived=true` 和非实时说明。

风险提示含 `risk_type/semantic_state/title/detail/level/evidence_ids`。主意图与模型健康提示引用当前可见买家证据，摘要还可引用当前客服原话作为上下文；工单 ID 提示在归档轨迹查看。分析结果始终 `human_required=true`。无可见买家消息时不发起模型请求，保留待确认；业务分类定义见 `src/taxonomy.py`。

## 本地 HTTP 接口

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | /api/overview | 官方统计、首条消息分流列表、是否配置模型（不返回密钥） |
| GET | /api/session?id=S00010&cursor=1 | 立即返回当前消息快照与规则安全基线；前端随后异步请求 Hybrid |
| GET | /api/tasks | 本地任务列表 |
| GET | /api/evaluation | 规则诊断评估 |
| POST | /api/model/config | `{api_key,model,base_url}`；只写入服务进程内存，响应不返回密钥 |
| POST | /api/analyze | `{id,cursor}`；前端自动异步增强或手动重试 Qwen + Hybrid，失败安全回退并附 model_error |
| POST | /api/tasks | `{id,cursor,title,note}`；幂等创建本地任务 |
| POST | /api/tasks/complete | `{task_id}`；标记本地任务完成 |

错误统一 `{error:字符串}`：无效参数 400、跨站请求 403、不存在 404。仅绑定 127.0.0.1，Host 白名单防 DNS rebinding，写请求检查 Origin、JSON 类型与 16 KB 长度。静态文件仅白名单，不开放目录浏览。SQLite 使用参数化查询并显式关闭连接。前端动态内容做 HTML 转义，CSP 限制脚本与资源来源。

## 模型、成本与可观测性

- 默认模型为 `qwen3.7-flash-2026-07-15`；可在顶栏内存配置入口或环境变量中改写，支持 HTTPS 服务或本机 HTTP 模型。
- 40 秒网络超时，输出上限 1200 tokens，JSON 输出，关闭思考模式；具体兼容性须用当前账号实测。
- 只发送当前会话最小上下文，不附整个 XLSX；不发送结构化收款账号字段。但消息原文仍可能含模拟隐私，生产接入前须另做脱敏过滤和权限治理。
- 缓存键包含提示词、模型、地址和上下文哈希；容量上限 256；进程重启清空。仅缓存校验后的模型语义，命中后重新应用当前 Hybrid 与健康门控。命中不产生新请求，页面显示 cache_hit 和本次 token 0。
- usage 只展示真实模型响应值；未调用不展示虚构 token 节省。不能在未验证地区/版本单价时将 tokens 换算为金额。
- 服务只记录本地 HTTP 请求路径与状态，模型错误不回显上游响应、密钥或堆栈。

## 现有限制与下一步

图片仅有路径，无法验证内容；当前不支持多模态。场景标签只能支撑主意图诊断，情绪/风险无金标。在线复测使用已参与诊断优化的开发数据，后续需补充人工盲测集、业务审核资料和客服对照试用。生产版本还需千牛插件身份验证、访问控制、授权的工具执行、完整审计事件、队列与超时回访策略。
