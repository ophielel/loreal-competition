# 在线评测低分分析与改进

## 旧版本问题定位

依据首次运行保存的276个场景响应分析，没有为解释错误重新调用模型，也没有修改官方标签。

1. **分类名缺少业务定义。** 首条消息有12个订单服务场景被模型判为退款打款；完整会话同类混淆13个。官方口径将普通退款进度、未到账放在订单服务，把少退补打、运费报销、独立补差等放在退款打款。旧提示词只列类别名，模型很难知道这种边界。
2. **主诉与处理结果混淆。** 完整会话有6个物流异常被判为补发换货。模型容易根据后来客服提供的解决方案分类，而原规则/标签口径更关注最早的明确主诉。自己选错色号、卖家错发色号、运输破损与商品泵头失灵也需要区分。
3. **信息不足仍按整段标签计分。** 首条消息有13个产品咨询场景被预测为待确认，通常只是问候。还有只有客服营销话术的时点。不能通过猜未来需求来提高这部分分数；新实现保持弃权，并单独记录没有买家证据的零调用场景。
4. **提示词与校验器契约不一致。** 提示词要求“至少引用一条买家消息”，旧校验器却拒绝所有客服消息引用。106个响应回退规则，使应用最终成绩不能等同于模型原始成绩。用新校验器离线重检旧输出，可以接受其中89个先前被拒的响应；没有买家支持的引用和非字符串字段仍被拒绝。另有10个旧响应将 uncertainty 输出为数组，旧提示词没有明确该字段类型，新提示词明确要求字符串。
5. **Hybrid 直接覆盖意图。** 旧实现接受模型输出后覆盖规则意图，没有业务依据强弱的仲裁。另一方面，规则回退又掩盖了模型自身错误。健康 action/guard 虽然保留，模型 reply 仍可能覆盖健康安全话术。
6. **缓存包含依赖规则的结果。** 旧缓存保存已经融合的部分字段，在同一消息快照、不同规则输入下可能沿用旧决策。新缓存只保存模型语义结果，命中后重新应用当前 Hybrid 和健康门控。

## 实现

- `src/taxonomy.py`：版本化业务定义，覆盖现有10类与待确认。标签名称不变，不读取样本ID、订单号或金标。
- `src/model.py` 提示词：按最早明确主诉分类，利用后文澄清而不被处理方案覆盖；明示退款、退货、物流与补发的边界；业务意图与健康风险分离。
- 校验器：允许当前可见买家与客服引用，至少一条买家证据；主意图证据只能来自当前可见买家消息；未知或未来ID仍失败；严格执行摘要200字、回复300字限制；空字符串 uncertainty 可规范化，缺失/非字符串不予放行；仅保留已定义字段，避免模型覆盖风险、人工确认等受控字段。
- Hybrid：规则与模型一致时记录 agreement；最早主诉存在明确业务依据、且支持规则原判时保留规则；其余采用模型语义。返回 `model_intent`、`intent_source`、`hybrid_reason`，方便追溯。健康风险始终保留高优先级、专员分流和安全回复。
- 零买家消息：正常保留规则/待确认，不消耗模型调用。不能把这个状态当作接口失败或伪装成成功模型响应。

## 验证顺序

先新增合成输入回归测试，复现引用、字段、健康回复和缓存问题，再实现修复。冲刺版共 48 项 Python 测试通过，覆盖模型契约、风险语义、承诺拦截、分类边界、全量历史截断、标签隔离和本地接口。统一测试数见 `data/release_summary.json`。

小样本以固定 SHA-256 排序、每类2个会话选取，共20个会话/40个时点。39次调用全部通过校验，1个无买家消息场景正常弃权。Hybrid 首条准确率80%、完整会话100%，与这批样本的规则基线持平；模型原始意图分别65%、90%。小样本通过后冻结配置，继续全量执行；已保存响应复用，不选取重复调用中最好的一次。

补充“主意图证据必须可见”的边界约束后，对40个小样本逐个离线回放，验证请求正文和业务/风险/回复结果完全一致，才复用这些响应。评测脚本另修正了零调用弃权的记账；旧小样本记录保留在本地，生产逻辑指纹与评测脚本指纹分别记录。

## 解读边界

本轮依据同源开发数据诊断并优化，**全量复测仍属于开发集诊断，不是独立留出评估**。分类定义参考官方业务分类，小样本也已在旧评测中出现，不能据此宣称泛化提升。

完整会话与首条消息输入不同，分别计分。健康风险、情绪和语义证据支持没有人工金标，不报告这些维度的准确率。合法ID不保证语义安全。历史运行包含不同模型，历史汇总只作为应用版本参照；如需排除模型差异，可在详细结果中对照使用相同模型的既有60个会话子集，仍需注明这是固定开发子集。

本轮全量结果与复现命令见 `ONLINE_EVALUATION.md`。原始请求/响应、失败尝试、用量与小样本记录位于本地 `deliverables/qwen-v2-eval-20260906/`，不含授权头。
